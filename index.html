Frontend vs Backend

Frontend

Es aquello que ven los usuarios e incluye elementos visuales, como botones, casillas de verificación, gráficos y mensajes de texto. Permite a los usuarios interactuar con la aplicación.

Tipos de frontend

Los principales lenguajes de Frontend para desarrollo web, como decíamos, son tres:

  • HTML

    • HTML (Lenguaje de Marcado de Hipertexto) es el lenguaje usado para esta definición y consiste en una estructura de marcas o etiquetas que sirven para definir elementos como párrafos, encabezados, imágenes, listas, etc.

  • CSS

    • El CSS podría definirse como un tipo de lenguaje que permite definir y crear la presentación visual de un documento ya estructurado y escrito en un lenguaje de marcado como puede ser HTML

  • JavaScript

    • Se integra con HTML y CSS para manipular el DOM (Document Object Model), lo que permite actualizar el contenido de la página en tiempo real sin necesidad de recargarla.

    Backend

    El back-end son los datos y la infraestructura que permiten que la aplicación funcione.

    Tipos de backend

    Los principales tipos de backend, son tres:

  • Python

    • l desarrollo de back-end con Python implica escribir código del lado del servidor que maneja las solicitudes del front-end e interactúa con bases de datos y otros recursos .

  • Java

    • Es vital para el multithreading, el uso eficiente de los recursos del sistema y el aumento del rendimiento de las aplicaciones

  • PHP

    • Un programador backend en PHP es aquel que se encarga de desarrollar la lógica de negocio, la interacción con bases de datos y la gestión de servidores en una aplicación web en PHP.
